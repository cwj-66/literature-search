# 论文相似度搜索

`find_related_papers` 与 `/api/papers/{paper_id}/recommendations` 共用推荐服务。
页面入口是论文阅读页的“论文相似度搜索”，路由 `/recommend?id=...`。

## 数据流

1. 优先读取中心论文的标题、摘要和已有关键词。大模型最多花18秒规划主题与关键词查询；不可用时退回原文词项。
2. 主题、关键词通道分别检索 arXiv 与 Semantic Scholar，每类每源最多2个查询，单个查询最多20条。按来源轮流选取，独立保留最多24篇候选。
3. 引用通道读取 Semantic Scholar 前20条参考文献、前20条被引文献。额外对最多2篇参考文献获取引用者，对最多2篇引用者获取参考文献，用真实路径发现文献耦合和共被引。按方向与扩展路径轮流选取，最多24篇。
4. 对三类候选跨源去重，最多72篇。所有候选与中心论文使用硅基流动 `BAAI/bge-m3`（`SILICONFLOW_EMBEDDING_MODEL`），调用 `embed_siliconflow(..., persist=False)`。不会回退到DashScope。向量只在该次调用的内存中存在，最终通过 `finally` 清空；不会读取或写入持久向量缓存。
5. 分别计算语义余弦、按当前候选样本IDF加权的关键词Jaccard、引用关联。直接引用记1，间接引用使用 `n/(n+1)`，其中n为本次发现的不同共同参考文献与共同引用者数量；它是有预算的排序特征，不是完整引文统计。
6. 三类独立排序，默认各保留最多10篇。同一论文可以属于多类，召回来源与最终关系类别分别记录。综合顺序用等权RRF，k=60；综合分数不是概率。
7. 只缓存论文元数据、分数、查询、关系依据和图数据，24小时过期，可手动刷新。不自动收藏候选，不检索未选择的本地论文或PDF。Agent也使用同一服务，仍先校验中心论文访问范围。

## 返回与展示

- `groups` 始终包含 citation、semantic、keyword，空结果和数据源失败均保留对应类别。
- `source_status` 保留各查询的来源、返回数量、失败状态；所有引用结果均为有限抽样，`complete=false`。
- `shared_reference_ids`、`common_citing_ids`、`shared_keywords` 和 `evidence` 提供可检查的依据。
- `network` 在缓存内保存，与推荐结果共用一次计算。直接引用用有向边，间接引用、语义、关键词分别用不同线型和颜色，线宽反映关系特征值。
- 向量服务失败时，主题分数为null且主题类别显示不可用；已有引用和关键词结果保留。
- Semantic Scholar 冷却状态按实际请求的API key指纹隔离；配置key或轮换key不会继承匿名请求的旧冷却。相同key仍尊重其真实429冷却。
- 当前关键词提取使用原文词项和连续短语，以及受原文匹配约束的模型关键词。未引入KeyBERT运行依赖，也未生成领域全库关键词共现统计。

## 验证

使用 `backend/tests/run_offline.py test_recommend test_similarity_search test_research_tools test_qa_scope` 运行断网回归。
覆盖三类独立名额、双源公平召回、间接引用路径、跨源去重、缺失向量降级、向量不入库、结果缓存和受限聊天工具。
页面验收样本通过真实评分函数生成；模拟API页面检查与真实上游联调须分别记录。

真实联调：MultiHop-RAG（arXiv:2401.15391）使用项目根目录 `.env` 中已配置的密钥，合并57篇候选，三类分别返回10篇；arXiv、Semantic Scholar检索、引用及间接引用扩展均成功。调用前后论文表和持久向量表数量不变。向量计算明确走硅基流动bge-m3。
