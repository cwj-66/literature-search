# 作品集文献演示

入口为 `/demo/paper-search/`，复用作品集已有的登录与匿名访客身份，不提供账号和个人云存储产品。

作品集 Nginx 的 `auth_request` 与文献后端都检查现有登录状态。后端从只读的 `portfolio_sessions`、`visitors` 表验证会话哈希、有效期、访客绑定与封禁状态，不信任客户端传入的访客请求头。

固定底稿在现有数据卷的 `demo-seed`；从线上原始数据库生成，只保留“RAG研究”“大模型幻觉”两个工作区，清除历史对话、Agent 任务、操作缓存和配置密钥。原始数据库不被覆盖。论文元数据、已有正文和解析结果均来自原项目数据，没有伪造示例分析或回答。

每位访客首次进入会生成独立的 SQLite 数据库和向量索引；任务检查点、内存事件频道和浏览器缓存也按访客隔离。所有访客共用同一个后端容器、串行后台队列和模型并发限制，不为每个人启动服务。模型 Key 只在现有服务器环境变量中保存。设置页只显示模型名称和配置状态，不能修改全局密钥。

闲置 7 天后清理体验数据；浏览器缓存含数据代次，过期重建不会复活旧内容。最多保留 100 个访客空间；每天每位访客最多 30 次研究/处理请求，全站最多 300 次；超过 128 MiB 的空间停止接收高成本请求，避免无限增加数据。一次研究可能包含多次模型或工具调用，请求额度不是精确的模型费用上限。底稿约占原数据的一部分，访客磁盘用量随操作增长。

部署使用 `compose.yml` 加 `compose.demo.yml`，前端通过 `PAPER_DEMO_BUILD=1 npm run build` 生成带路径前缀的资源。主站 `/api/` 和 `/assets/` 继续属于客服 Agent。加载 `nginx-portfolio-paper.conf` 到现有作品集 TLS server；将文献子域名改为跳转到作品集演示入口，避免旧公开入口绕过登录。保留部署前的配置、前端、镜像和数据库备份，以便回滚。
