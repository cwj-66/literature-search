# 研究领域与领域演进

## 使用流程

论文完成原有分析时，在同一次证据提取和核对中识别 1–3 个研究领域，并保存论文与领域的对应关系。证据不足可为空，不按关键词硬匹配。已分析的旧论文可在“研究领域”页面点击“识别已有论文领域”补充，无需重新下载 PDF。

新入口在工作区侧栏“文献推荐”下方；知识图谱右上角“领域演进”也能进入。选择领域后手动点击“开始分析”或“重新分析”。导入论文只识别领域，不自动运行整个领域的检索报告。

## 什么算研究领域

领域是有稳定学术名称、能持续积累多篇论文的共同问题族或方法族。人工智能、计算机视觉等学科过宽，只作上级；单个模型、数据集、论文标题过窄。例：LoRA 变体归入参数高效微调，DDPM 归入扩散模型，研究 GraphRAG 的论文可归入检索增强生成；是否同时属于知识图谱取决于实际研究内容。

模型输出中文名、完整英文规范名、别名、可选上级及原文摘录。摘录先做真实原文校验，再由模型核对研究主体。规范译名不要求逐字出现在摘录里，但原文必须支持论文确实研究该问题。名称归一化使用大小写、空格、连字符和少量已知同义名；不采用另一个模型调用强行合并相邻领域。开放领域标签仍可能存在同义名分裂，这是当前边界。

核心研究领域作为原有论文分析的第六块，与其他分析一起输出JSON并存表，不额外发起领域识别或修复模型调用。全文解析沿用原有流程；原有流程仅能提供摘要时如实标注摘要依据，不把摘要测试描述为全文分析。

## 检索与证据

复用已配置的 arXiv / Semantic Scholar API、密钥与重试机制，不建立全量论文向量库。先检索时间两端并由模型规划至多 4 组奠基、突破、近期、综述查询，再检查候选中缺失的关键工作，至多追加 2 组检索。模型记忆只能提出待检索的准确标题，不能直接成为报告事实。

最多保留 96 篇有年份和摘要的公开候选，优先保留定向检索的关键工作，并按早期、近期、影响指标平衡抽取至多 24 篇。每篇提供至多 1600 字符摘要片段以控制模型上下文；这会限制细节和局限的覆盖，不声称全文分析。引用数只是采样指标，不自动代表技术突破。

时间线使用 API 年份排序，展示作者贡献和模型归纳的意义，不声称节点间有直接引用或继承。每项结论必须引用实际 API 论文 ID 和提供过的逐字摘要片段；再经过独立语义核对。热点和潜在方向只采用近三年材料，方向明确展示假设与不确定性。没有依据的条目删除，检索样本不足时不生成虚构报告。

## 存储与后台任务

- `paper_fields`、`field_identifications`：现有私有论文数据库内，随访客隔离。移除工作区论文后不再列入该工作区领域。
- `research-fields.sqlite3`：位于主论文数据库同目录，保存全局领域规范名、别名和报告。不保存工作区 ID、上传正文或私有论文列表；报告材料仅来自公开 API。
- 同领域在不同工作区可直接读取同一报告。缓存按提示词版本和年度区分；并发请求合并成一个任务；取消、重启或超时租约可恢复。
- 重新分析期间保留旧报告，失败不覆盖。跨年度重新分析也保留上一年度报告；报告本身的生成日期始终可见。
- 旧论文补标属于本地后台任务，全局报告属于独立公共任务。演示站继续沿用原有登录和耗费请求配额，不开放匿名私有数据。

## 参考实现

借鉴成熟项目的设计方式，未引入新 agent 框架或复制其整个产品：

- [FutureHouse / PaperQA](https://github.com/Future-House/paper-qa)：先收集证据、再回答，每项论断回到来源。
- [LangChain / Open Deep Research](https://github.com/langchain-ai/open_deep_research/blob/main/src/open_deep_research/prompts.py)：分阶段规划检索、检查覆盖缺口、限定轮数。仅借鉴提示词组织方式。
- [AllenAI / SciRepEval](https://github.com/allenai/scirepeval/blob/main/scirepeval_tasks.jsonl)：论文可对应多个领域标签。
- [Semantic Scholar Graph API](https://api.semanticscholar.org/api-docs/graph)：年份、摘要、引用量等公开元数据。

## 验证范围

新功能测试覆盖领域归一化、多标签、跨工作区复用、访客隔离、任务合并与恢复、失败保留旧报告、API 成员校验、逐字证据与近期年份检查、两轮检索和 DOI 去重。浏览器用明确标注的示意材料验证时间线、视图切换、手动重分析和 390px 布局；这些示意材料不写入业务数据。

真实模型与公开 API 检查使用隔离容器，不挂载线上用户数据，不替换线上服务。真实源的返回状态和报告质量以当次测试结果为准，不能把接口部分成功描述成两个源均成功。

2026-10-21 最终真实 RAG 报告检索到 87 篇候选，24 篇纳入模型材料，形成 4 个时间点、2 个热点、1 个潜在方向。时间点包括 2020 年 RAG 原论文、2022 年多模态检索增强模型和 2024 年图检索方向。Semantic Scholar 当时返回 HTTP 403，arXiv 部分请求发生限流并重试；该报告属于部分源结果，不是完整领域史。上述演进测试使用公开 API 摘要；不代表完成了真实 PDF / MinerU 的新增端到端验收。新论文第六块与原有分析同次调用、事务存表由相关测试验证。
