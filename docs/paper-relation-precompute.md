# 论文关系预计算与展示

论文保存与 `relation_jobs` 排队在同一个 SQLite 事务完成。后台单工作协程复用现有三维推荐算法，保存每个维度排名第一的结果、关联强度、依据和计算时间到 `relation_snapshots`。候选只保存在快照中，不自动加入论文库，也不递归扩展。

应用启动会补齐旧论文任务、复用现有推荐缓存，并恢复未完成任务。失败最多自动尝试三次，按退避时间排队；已保存的有效关系不会因临时失败而被清空。新论文入库不会使其他论文的快照失效。`RELATION_PRECOMPUTE_WORKER=0` 可以关闭工作协程。

`POST /api/papers/relate` 只读取已入库论文和持久快照，不调用检索、向量或语言模型。`refresh=true` 只申请后台重算，仍立即返回已有结果。返回的 `pending_ids` 表示后台尚在准备的主论文；前端每 2.5 秒读取一次，全部完成或终止后停止轮询，取消选择和离开页面会取消请求和计时器。

同一论文只创建一个节点，选中后升级为主节点；已有关系与共享子节点按身份合并。每维度展示一篇推荐，但节点可以连接更多来自其他主论文的关系。图上线条无方向箭头，引用方向保留在详情中。

空间图使用简洁圆点、三种明显的关系色、短标签和悬停完整标题。新增节点、升级节点与视图变化有过渡动画，系统开启“减少动态效果”时停用动画。初次计算或失败重试仍需要等待，已有快照仅需本地读取和渲染，不承诺绝对零延迟。
