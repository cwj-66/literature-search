# 工作区论文关系

工作区侧栏的“论文关系”使用 `/w/:id/compare` 路径。顶部展示当前工作区的论文，支持横向滚动及标题、作者、年份搜索；选中论文后，以该论文为中心探索引用、语义和关键词关系，无需预先完成单篇分析。

页面复用现有 `/api/papers/{id}/recommendations` 服务。每个分支取对应 `groups` 中排名前五的真实结果，不足五篇时按实际数量展示，不补造节点。引用为紫色实线，主题为蓝色虚线，关键词为绿色点线。连线粗细和节点数值展示服务返回的综合关联强度；类别排序沿用服务的各类排序。同一篇文献可分别出现在多个分支，图中分别统计唯一文献数和关联数。

点击节点可查看关联理由、共同关键词和引用证据，再进入论文详情。图支持拖动画布、放大缩小、重置视角，以及点击图例突出某一类关系。手机端横向滑动查看完整图，初次进入定位在中心论文。

切换论文会取消旧请求，并缓存当前页面已读取的推荐结果；不会导入候选文献或保存候选向量。更新关系按钮显式重新计算。加载失败显示重试入口，各类数据不足时保留真实的空状态。

原有多论文内容对比保留在 `/w/:id/compare/table`，单篇阅读、多选工具条和知识图谱的内容对比入口已同步到该路径。

本次一同发布知识图谱的主题共现聚类、主题战略坐标及演化图；主题统计明确区分全库 GET 和工作区 POST。工作区 POST 的空列表只返回空结果。
