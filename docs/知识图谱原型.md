# 知识图谱交互原型

入口 `/graph`，本地分析库和论文详情页均有链接。原型提供RAG示例与本地论文库两种数据模式。

## 实体与关系

- 论文 → 作者：论文元数据中的作者关系。
- 论文 → 关键词：已有AI分析中的关键词；不重新调用模型。
- 论文 → 期刊或会议：论文元数据中的发表来源；缺失时不虚构。
- 同名实体仅按大小写和空白归并，作者未使用ORCID消歧，关键词未做完整同义词归一。

本地模式通过 `GET /api/knowledge-graph` 读取最近80篇入库论文及其最新分析结果。图谱由现有SQLite数据动态构建，不新增图数据库或外部搜索调用。画布为可读性限制节点数量，页面统计和时间视图采用当前筛选的全部样本；页面明确显示范围。

支持搜索、累计年份筛选、实体类型开关、点击聚焦、关联实体跳转、缩放和平移。时间视图按论文年份分组；主题分布统计当前样本中每年包含某关键词的论文篇数。

## 演示数据范围

RAG示例人工选取8篇论文，作者仅列部分，主题手工标注，年份使用arXiv预印本年份。不是自动搜索结果，不是全领域统计。部分刊会已对照公开出版记录：

- [REALM，ICML](https://proceedings.mlr.press/v119/guu20a.html)
- [RAG，NeurIPS](https://papers.neurips.cc/paper/2020/hash/6b493230205f780e1bc26945df7481e5-Abstract.html)
- [HyDE，ACL](https://aclanthology.org/2023.acl-long.99/)
- [RAGAs，EACL](https://aclanthology.org/2024.eacl-demo.16/)

预印本年份可能早于会议年份。本原型的实体连线不代表引用、因果或技术继承。

## 演进脉络与热点趋势的后续方向

首先展示已有样本的论文时间线和主题年度分布，不为每次查看重新搜索。

例如RAG样本可以按检索与生成、评估与自我反思、检索纠错与图结构等研究主题组织。只有在原文说明和引用元数据足够时，才进一步展示“引用”“改进某方法”等有方向的关系；发表先后或主题相似本身不能证明继承关系。

若要展示领域级趋势，应建立可持续更新的专题语料：固定检索范围和时间窗口，记录查询、来源、更新时间与覆盖量，定期或手动增量获取元数据，按DOI/arXiv ID去重，并归一化主题。无需先下载全部PDF，也无需在浏览图谱时反复调用大模型。

趋势优先展示同一年度样本中各主题占比、论文数量和数据覆盖情况。比较增长时控制相同来源与检索条件，并区分当年未完整数据。人工挑选的少量论文和来源返回的前100条相关结果都不能直接当作领域热度统计。

后续可替换为Neo4j存储以满足正式知识图谱的数据建模需求；本版先验证实体、交互与展示方式。
