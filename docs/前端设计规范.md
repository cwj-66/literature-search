# 前端设计规范

本文件记录 `frontend/` 的视觉体系与交互约定。所有页面共用同一套 token，改样式时先改 token，不要在页面里写死颜色、圆角、阴影。

## 1. 文件结构

| 文件 | 职责 |
| --- | --- |
| `src/theme.ts` | 颜色的唯一来源。导出 `tokens`、注入 `:root` 的 `cssVars`，以及 Ant Design 的 `antdTheme`。 |
| `src/styles/tokens.css` | 结构型 token（间距、字号、动效、布局尺寸）、元素重置、关键帧、antd 全局润色、`prefers-reduced-motion` 兜底。 |
| `src/styles/base.css` | 应用外壳（侧边栏 / 工作区外壳）、页面框架、共享原子组件（面板、状态胶囊、标签页、论文行、证据块）、路由过渡。 |
| `src/styles/pages.css` | 各页面模块（检索、工作区、助手、论文库、对比、图谱、精读、文献库、研究台、设置）。 |

`src/main.tsx` 按 `tokens → base → pages` 的顺序引入，并在渲染前把 `cssVars` 写到 `document.documentElement`，保证 CSS 与 antd 组件使用同一套色值。

## 2. 颜色

- 中性色：`--ink`（标题）→ `--text`（正文）→ `--muted`（次要）→ `--faint`（辅助）。四级都满足 WCAG AA（白底 ≥ 4.5:1）。
- 品牌色：`--accent`（靛蓝 `#4f46e5`）、`--accent-hover`、`--accent-active`、`--accent-soft`、`--accent-tint`、`--accent-border`。
- 语义色：`--success` / `--warning` / `--danger` / `--info`，各自配 `-soft`（背景）与 `-border`（描边）。
- 可视化专用色：`--viz-blue`、`--viz-violet`、`--viz-amber`、`--viz-rose`、`--viz-green`、`--viz-teal`，用于图谱节点、速读高亮、图标底色。
- 页面底色 `--canvas`，卡片底色 `--surface`，弱底色 `--surface-muted` / `--subtle`；描边只用 `--line`、`--line-strong`。

## 3. 字体与排版

- 界面字体 `--font-ui`（Inter → Segoe UI → 系统中文字体）；论文标题、摘要、问答正文使用 `--font-read`（衬线），正文行高 `--lh-read: 1.85`。
- 字号刻度：`--fs-2xs 11 / --fs-xs 12 / --fs-sm 13 / --fs-ui 14 / --fs-md 15 / --fs-lg 16 / --fs-h2 19 / --fs-h1 26 / --fs-display 34`。
- 标题字重 600–650，字距 `--tracking-tight`；小标签使用 `--tracking-wide` + 大写英文时统一大写。

## 4. 间距、圆角、阴影

- 间距只用 `--s1…--s8`（4/8/12/16/24/32/48/64）。
- 圆角：`--radius-sm 6`、`--radius-md 8`（控件）、`--radius-lg 12`、`--radius-card 14`（卡片）、`--radius-xl 16`、`--radius-pill`。
- 阴影：`--shadow-xs`（卡片静息）→ `--shadow-md`（悬浮）→ `--shadow-lg` / `--shadow-pop`（浮层）；主按钮用 `--shadow-brand`。
- 焦点态统一 `--focus`（3px 品牌色光环）。

## 5. 布局

- 顶层页面：左侧 244px 导航（≤860px 变顶部横向条）+ 内容区，内容最大宽 1360 / 1024 / 792。
- 工作区：60px 顶栏 + 216px 导航卡 + 内容卡；≤960px 导航变单行横向滚动条，内容改为自然流。
- 论文精读：正文列（自适应）+ 366px 侧栏；≤1180px 收窄，≤960px 上下堆叠。
- 检索结果：220px 筛选卡 + 结果列表；≤1000px 筛选变横向可换行。

## 6. 交互与状态

- 路由切换：非工作区路由整页 `fade-rise`（260ms）；工作区外壳保持稳定，只让内容区入场。
- 列表入场：卡片/论文行按序错峰 40ms 递增，最多 5 级；动画使用 `backwards` 填充，结束后不锁定 `transform`，保证 hover 抬升仍然生效。
- 悬停：卡片抬升 1–2px 并加 `--shadow-md`；行内链接变色不位移；按钮只做颜色与阴影过渡。
- 加载：路由级 spinner、列表骨架屏（自定义 shimmer）、分析进度步骤条、图谱渲染提示；禁用态文字保持可读。
- 动效尊重 `prefers-reduced-motion`：全部过渡/动画降到 0.001ms。

## 7. 视觉验收

`frontend` 目录外的一次性脚本（Playwright + 本机 Edge）用于回归：

- 布局不变量：导航宽度、卡片圆角/阴影、栅格列数、移动端横向溢出。
- 对比度与点击目标：遍历 DOM 计算 WCAG 对比度，检出 < 24px 的可交互元素。
- 交互流程：新建工作区弹窗、列表勾选、精读切换、对比选文、检索排序/排除、设置编辑、抽屉、助手输入框状态。
- token 一致性：统计页面上出现的圆角、字号、文字颜色种类数量，防止页面级硬编码。

## 8. 扩展约定

- 新增页面：先复用 `.page` / `.ws-page` 框架与 `.page-head`，再写页面专属类，颜色与间距一律引用 token。
- 新增组件：优先使用 `--surface` + `--line` + `--shadow-xs` 的“卡片”语言；状态用 `.status` 胶囊；空状态沿用 `EmptyState` 的插图式卡片。
- 新增 antd 覆盖：写入 `tokens.css` 的 antd 润色段，或 `theme.ts` 的 `components`，不要散落在页面 CSS 里。
